# 验证与阶段验收

当前阶段只验证文档完整性、链接、依赖顺序和工时拆分。以下测试是后续开发的验收要求，不表示已运行。

## 每份 spec 的完成标准

实现符合当前 spec 范围，关键异常有明确行为；新增/修改契约同步 OpenAPI 与前端类型；跨层/跨模块导入约束通过；相关自动测试通过；实际验收结果记录在 spec 中。无须每个小改动都运行完整 Java 测试集，未修改引擎时用限定的 Web 测试及真实 SDK 集成烟测。

不为只转发参数的函数大量编写镜像式测试。重点验证权限、参数合并、任务状态、结果语义、SDK 契约和用户闭环。前端纯视觉调整用页面检查；数据来源切换、错误恢复等交互用自动化验证。

## 测试层次

| 层次 | 工具建议 | 重点 |
| --- | --- | --- |
| 后端业务/接口 | pytest、FastAPI 测试客户端 | 权限、options、状态冲突、幂等、分页、错误映射 |
| 持久化/队列 | 临时 PostgreSQL + pytest | 原子领取、失联占用、唯一约束、结果发布一致性 |
| SDK 适配集成 | 固定 SDK + 当前分支 Batfish | 问题加载、参数/结构、诊断、路由、trace、多快照隔离 |
| 前端逻辑 | Vitest + Testing Library | 参数展开、旧请求隔离、状态/空结果、多路径 |
| 浏览器闭环 | Playwright | 两个用户、上传到分析、刷新恢复、角色权限 |
| 人工可用性 | 桌面浏览器 | 中文可读、视觉一致、关键限制可见、键盘可用 |

真实 SDK 集成测试需要可用引擎时单独标记；环境缺失应明确为未验证，不能将 mock 通过当作集成通过。

## 五类重点失败条件

1. 两名用户交错分析不同快照：返回结果的网络/快照、参数和配置内容必须正确；cookie 身份不能写入共享 Session。
2. SDK 已开始工作后 worker 崩溃：不可自动重复执行或假取消；系统展示未知占用并阻止新任务直到对账。
3. 原始配置部分解析/不支持：结论附带模型限制；华为/H3C IPv6/SRv6/EVPN/ACL 边界不能被绿色状态掩盖。
4. 同名、ZIP 穿越/膨胀、多根目录或乱码：确定拒绝或保留原始字节处理，错误不泄露配置内容。
5. 输出包含 NaN/集合/嵌套 Trace/超大量结果：JSON 合法、复杂结构保留、稳定分页、明确截断且不声称结果完整。

这些用例分别落实在 SDK 会话、worker 恢复、初始化质量、上传和结果契约 spec，不留到最后一次联调才发现。

## 数据与比较方法

使用仓库 networks/example 和合成小网络样例；华为/H3C 使用可公开的脱敏 fixture。不得把 docs/configuration 中真实设备采集、认证材料或本地私有配置复制进新测试仓库。故障/差异样例通过明确可解释的配置变化产生，不随机生成无法判读的预期。

对照同一引擎、SDK、输入快照、问题和参数的直接 Pybatfish 输出。表格比较稳定字段、归一化集合和确定排序；trace 比较 flow、disposition、hop 顺序及关键动作。不要比较 pandas 的展示字符串或依赖引擎无保证的行顺序。

## 阶段门槛

### 阶段 1：MVP-25

- 全新部署可初始化管理员、创建成员、登录/退出/改密，停用后旧会话失效。
- 普通成员上传有效配置并获得初始化诊断；失败文件可定位，未支持功能有说明。
- 设备/接口、routes、lpm-routes、traceroute 与直接 SDK 输出对照一致。
- 多用户不同快照不串数据；排队取消、重复提交、任务刷新恢复和服务重启行为正确。
- 普通成员不能删除资源或管理用户，管理员删除与在途任务互斥。
- 表格和路径按需展示，基础/高级模式一致，原始信息与导出保持可追溯。
- 记录约 100 台设备样例（若可取得）的实际耗时/内存/结果体积；无法取得时明确已验证规模，不宣称达到容量目标。

### 阶段 2：ADV-10

在首版回归通过基础上验证拓扑边来源、BGP 模型状态、ACL permit/deny/隐式拒绝/遮蔽/空匹配，专家入口只接受已登记问题；不支持厂商能力不可标成已验证。

### 阶段 3：ADV-18

验证基线/候选方向、配置与路由差异、差异可达性新增/消失、故障派生快照不改变基线、失败恢复；对比的空结果只在查询范围和模型条件内解释。

## 文档自检

所有 Markdown 相对链接必须解析；每个 spec 有唯一 ID、阶段、依赖、工作量、需求、设计、测试、验收及非目标；依赖无环并且目录与阶段一致。索引合计应等于各 spec 工时之和。实现后通过 spec 状态区记录实际执行日期、验证命令和结果，而不是改写最初需求来掩盖未完成项。
