## 测试与验收

- 跨快照内容和结果不串用；页面刷新可找回任务。
- 基础/高级相同有效参数得到同样分析结果。
- 解析不完整、不可达、空结果、失败、中断可区分。
- 只以实际测试规模报告容量，无样本不宣称100设备已达标。

后端测试在 `web/backend` 下使用 `uv run pytest` 指定上述测试文件；集成测试连接版本固定的隔离 Batfish 测试网络，不操作团队生产网络。

浏览器验收在 `web/frontend` 下使用 `pnpm exec playwright test --config playwright.acceptance.config.ts`；测试账号和快照应使用隔离环境。

验收成功同时要求：契约与文档一致、失败行为可解释、无跨层/跨模块越界、没有把 mock 验证宣称为真实 SDK 验证。共享约束中的身份、版本、模型覆盖和结果截断规则均适用。
