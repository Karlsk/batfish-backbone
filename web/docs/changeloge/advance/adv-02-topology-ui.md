## 需求与目标

用户可在可控规模的拓扑中定位设备及邻接关系。

- Cytoscape.js、视图切换、设备聚焦、一跳邻居、筛选、接口详情和路由入口。

## 设计与接口

- 消费 graph 结果，不在前端重新推导协议邻接。
- 默认聚焦设备/一跳，上限200个可见节点；超限显示范围限制而非静默裁剪。
- 点击详情沿用当前 network/snapshot，拖动节点仅修改视图布局。

沿用 api → service → controller；所有跨业务模块调用经过 service。非 SDK 存储由本模块 repository 负责。浏览器不接触 SDK 会话或连接参数。

- topology.test.tsx：切换快照旧图不会覆盖新图，实例被清理。
- 重复边/孤立节点/长名称/200节点上限展示明确。
- 图例区分三层推导和协议关系，不标实时链路通断。
