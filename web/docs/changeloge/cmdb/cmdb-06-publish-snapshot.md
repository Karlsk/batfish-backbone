# CMDB-06 原子组装、初始化与最新快照晋升

- 状态：待开发；阶段：采集一期；依赖：[CMDB-03](cmdb-03-manual-drafts.md)、[CMDB-05](cmdb-05-chunked-push.md)；预计：3 人天。

## 交付与接口

`finalize` 在验证完整长度、整体哈希、ZIP 契约和声明完整性后创建幂等 worker 任务。采集包与人工草稿都走统一发布 service：写入不可变版本、分配新的 Batfish 内部快照名、初始化并记录解析质量；仅满足发布门槛时更新网络“最新成功采集快照”指针。历史快照和原始包持续可读。部分设备失败、源时间窗口不一致、SDK 失败或引擎占用未知时保留运行诊断、阻止晋升；取消/重试遵循现有 job 恢复约束，不重复创建候选。旧手工 ZIP 流程原样可用。

## 验收

两次定时推送产生可切换版本；同一 `collection_id` 重放不重复创建；不完整或损坏包与初始化失败不移动最新指针；人工发布不会冒充采集。真实 PostgreSQL、worker、Batfish r1/r2 与四设备集成以及服务重启恢复通过。
