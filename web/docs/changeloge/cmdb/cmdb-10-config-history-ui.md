# CMDB-10 设备配置、模块与历史页面

- 状态：待开发；阶段：采集一期；依赖：[CMDB-09](cmdb-09-topology-ui.md)；预计：3 人天。

## 交付与接口

拓扑节点详情提供设备台账、配置原文（分页/按需加载）、BGP/OSPF/ISIS/接口模块定位、配置来源/采集时间、相邻两个历史版本差异。调用 CMDB-02、07 和现有快照文件/差异 service；管理员可从此进入 CMDB-03 人工草稿，成员只读。编辑草稿与查看采集事实视觉分离。模块索引不可用时仍能查看原文，并标记缺失、未知编码或解析限制；历史选择作用于整页，不能把新版台账配旧版配置。全量下载沿用已有权限与大小约束。

## 验收

两版设备改名/配置变化、无模块、非 UTF-8、超大配置分页、资源失效、跨网络拒绝及键盘导航浏览器测试通过；技术/专家原页面与领导入口无回归。
