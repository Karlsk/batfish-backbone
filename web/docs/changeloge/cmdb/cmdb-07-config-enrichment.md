# CMDB-07 配置派生信息与模块索引

- 状态：待开发；阶段：采集一期；依赖：[CMDB-06](cmdb-06-publish-snapshot.md)；预计：2.5 人天。

## 交付与接口

快照就绪后用已登记的解析能力补全设备名称、型号可用字段、接口 IP/VRF、BGP/OSPF/ISIS 模块索引与解析质量，标注 `collector/config/model/manual` 来源和采集时间。采集 `node.json` 是设备台账优先展示值；冲突不静默覆盖，保留来源与差异提示。不能从配置可靠得出的速率、双工、实际会话等保持 `unknown`。配置正文按内容哈希在文件卷存储，模块视图保留原始行号和“解析不完整”状态，不擅自把厂商差异归一为已验证事实。派生失败不删除原始配置与设备。

## 验收

Cisco 四设备与 r1/r2 真实初始化后校对派生字段和来源；缺失/重复 hostname、未识别厂商、解析警告、模块缺省和同一快照重复索引都给稳定结果。读接口不得同步跑 SDK，受影响的原技术端查询不回退。
