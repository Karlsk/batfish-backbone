# CMDB-03 人工设备、链路与配置草稿 CRUD

- 状态：待开发；阶段：采集一期；依赖：[CMDB-02](cmdb-02-read-api.md)；预计：3 人天。

## 交付与接口

管理员可从某个网络快照创建人工草稿，并通过 `POST/PATCH/DELETE /api/v1/networks/{network_id}/cmdb/drafts/{draft_id}/devices|links|configs` 管理设备、物理连接和配置文件；GET 可预览草稿及相对基线的差异。`expected_version` 防并发覆盖。设备/接口引用需存在；删除设备前处理所连链路与配置引用，不产生悬空边。保存只改草稿，不原位改采集版、不调用 SDK、不下发设备；发布由 CMDB-06 执行。采集源与人工来源显示分开，人工修改不被下一轮采集静默合并。

## 验收

覆盖完整 CRUD、权限/CSRF、网络隔离、旧版冲突、重复链路、悬空端点、配置大小和路径限制、草稿删除/重试。旧快照内容哈希保持不变，成员可读草稿但不可写。更新 OpenAPI 类型。
