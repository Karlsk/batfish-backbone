# CMDB-09 快照物理拓扑中心

- 状态：待开发；阶段：采集一期；依赖：[CMDB-08](cmdb-08-topology-api.md)；预计：3 人天。

## 交付与交互

在现有 `web/frontend` 技术工作台建立以物理层为底图的拓扑中心，复用主题和 Cytoscape 基础。顶部选网络/快照及图层，叠加 L3/BGP/OSPF/ISIS 时用颜色、图例和来源明确区分；按需请求或提交分析，不阻塞物理图。悬停显示设备简卡、左击固定详情、右击菜单提供配置与拟变更入口；同样的菜单有键盘/触屏按钮。底部“变更推演”展示当前草稿状态，第二期完成候选能力前只进入草稿入口，不显示假推演结果。提供搜索、适应画布、局部下钻和大图上限提示，历史切换清理旧响应。

## 验收

真实浏览器在明/暗主题、双用户下完成两个快照切换、孤立节点与多链路、叠层加载/失败、右键和键盘菜单、缩放与截断提示；画布无物理输入时明确显示“未提供”，不绘制推测边。前端类型、单测、构建和 Playwright 通过。
