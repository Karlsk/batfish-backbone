# CMDB-11 第一期真实环境累计验收

- 状态：待开发；阶段：采集一期；依赖：[CMDB-10](cmdb-10-config-history-ui.md)；预计：2 人天。

## 验收门槛

在隔离 Batfish、PostgreSQL、API、worker 和生产构建前端上，从空库迁移开始，用 r1/r2 与 Cisco 四设备分别做标准 ZIP、分段重试推送、人工 CRUD、两个历史版本、物理拓扑及 L3/BGP/OSPF/ISIS 叠层。覆盖管理/普通/采集身份、失败/中断/恢复、同 ID 幂等与篡改、完整性缺失、最新指针不错误晋升、暗/亮主题和浏览器交互。现有 MVP/ADV/LDR 必需回归、OpenAPI 类型、Ruff、前端构建/单测/Playwright、部署重启及 HTTPS 恢复流程应保持通过。

## 交付

回写逐篇证据矩阵和采集方手册（示例 JSON/ZIP、分段调用、错误码、历史查看）；记录真实版本、计数、配置哈希、吞吐与测试规模。只证明 Web 流程与固定模型的行为，不宣称现场转发或超出测试规模的容量。全部必需验收通过才允许 SIM-01。
