# SIM-13 代表流路径变化与路径策略

- 状态：待开发；阶段：推演二期；依赖：[SIM-12](sim-12-business-reachability.md)；预计：3 人天。

## 交付与接口

从业务意图的显式地址或有限网段生成可复现的代表流集合（最多 32 个，记录采样规则）；在两版用相同报文约束做 traceroute，比较规范化节点/接口路径集合、分叉和终止 disposition。分别报告 `path_changed` 与连通性变化；期望必经/避开设备策略按每条已返回路径检查，结果截断/路径不全为 `unknown`。不把一条样本路径当成整个网段全部路径，也不把设备名变更误判为路径变化。

## 验收

四设备路由成本变更构造“仍可达但改道”，以及多路径增减、未变、缺起点、32 条上限、截断和路径策略违反；两版原始 traceroute 可逐条下钻。
