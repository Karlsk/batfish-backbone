# SIM-17 第二期真实环境累计验收

- 状态：待开发；阶段：推演二期；依赖：[SIM-16](sim-16-results-ui.md)；预计：2.5 人天。

## 验收门槛与交付

隔离 PostgreSQL、固定 Batfish、API/worker 和前端生产构建上使用两套合成拓扑，先走 CMDB 定时分段推送与历史切换，再完成两设备完整配置/脚本输入、候选快照、固定比较、Underlay 模型差异、链路配对、环路/有界黑洞/IP 冲突、业务连通性与路径分报、双向隔离。覆盖成员/管理员/采集凭证、失败/中断/恢复、同一运行幂等、意图与配置版本锁、未知/截断/模型限制；浏览器测试拓扑菜单、编辑、证据下钻和旧汇报。累计回归原 MVP/ADV/LDR、第一期、HTTPS 部署恢复和 API 类型。

记录实际测试规模、原始/派生输入哈希、代码与引擎身份、检查结果和残余限制；只在必需检查全通过后把阶段标为完成。现场真实设备的转发精度、生产容量和厂商全量 CLI 语法不在本批结论中。
