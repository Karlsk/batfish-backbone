# SIM-14 网段隔离一致性

- 状态：待开发；阶段：推演二期；依赖：[SIM-12](sim-12-business-reachability.md)；预计：2.5 人天。

## 交付与接口

对期望 `isolated` 的意图，分别以 A→B、B→A 的显式起点/源/目的/协议/端口约束搜索成功流；若找到则报告隔离破坏、示例流和 ACL/路径证据。对候选与基线分别检查，再报告新增/持续/已修复。无成功流见证需标 `no_witness_within_scope` 及前提，只有模型支持、范围完整且查询未截断时才可标“该范围内符合意图”；未知和未建模不可判通过。

## 验收

单向许可、双向阻断、ACL 放开、网段边界、跨 VRF、无起点和引擎限制都按方向输出；不把 `testFilters` 的单 ACL 行为误作端到端隔离。
