# SIM-08 物理互联链路两端配置规则

- 状态：待开发；阶段：推演二期；依赖：[SIM-07](sim-07-session-diff.md)；预计：3 人天。

## 交付与接口

只对同一快照中已验证的物理两端接口执行速率、双工、MTU、VLAN 封装、自协商、L2/L3 模式和 L3 IP 子网配对规则。每项输出 `pass/fail/unknown/not_applicable`、两端原值、来源、解析器版本和规则解释；一端未显式配置的默认值为 `unknown/device_default`，无受支持厂商默认表时不直接判不一致。Trunk VLAN 比较语义需看允许集合与 native VLAN；点到点 IP 子网按掩码及 VRF 判断。基线和候选各做一遍并报告变化，物理链路缺失则不运行。

## 验收

Cisco 合成链路成对正常/不一致、单端缺值、默认值、异 VRF、多链路、未解析厂商和断链均有可定位证据；不以 L3 推断边替代物理链路。
