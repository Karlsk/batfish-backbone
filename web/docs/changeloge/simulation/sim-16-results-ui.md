# SIM-16 变更推演结果页面

- 状态：待开发；阶段：推演二期；依赖：[SIM-06](sim-06-change-ui.md)、[SIM-15](sim-15-run-summary.md)；预计：3 人天。

## 交付与交互

从拓扑底部推演按钮进入运行进度与固定结果。首屏只展示基线/候选、变更设备、Underlay/业务/隔离三类结论与未覆盖数；再下钻到变化范围、示例流、路径 Before/After、链路两端值和技术证据。模型邻接与真实观测分列；无观测写“未同步”，缺字段写“未知/设备默认”。右侧可把结果引用到领导端固定汇报，但汇报的事实版本不可改。错误、部分成功和源证据失效有独立状态，暗/亮主题和大图性能可用。

## 验收

真实浏览器覆盖两设备变更、脚本转换失败、协议/链路差异、仍可达但绕路、单向隔离破坏、未知/截断、旧汇报保留和双用户权限；不会把空结果、没有运行及通过混为一类。
