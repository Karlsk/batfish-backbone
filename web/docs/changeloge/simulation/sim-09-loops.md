# SIM-09 转发环路见证

- 状态：待开发；阶段：推演二期；依赖：[SIM-05](sim-05-candidate-snapshot.md)；预计：2.5 人天。

## 交付与接口

经 analysis controller 对固定引擎/SDK 的 `detectLoops(maxTraces=...)` 先做真实兼容验证，再在基线/候选分别执行并归一化示例流、节点/接口路径和变化类型。任务异步、串行占用引擎，设置输出与时间预算，结果保留截断/超时/模型版本。UI 文案为“在本次模型查询中发现环路见证 / 未发现见证”，不能写“全网无环路”。查询错误独立失败，不吞并其它检查。

## 验收

合成静态环路的正例和无环路对照、两版差异、超时/截断、SDK 原始行映射与无效 options 通过；真实测试连接固定版本 Batfish，不能只靠 mock。
