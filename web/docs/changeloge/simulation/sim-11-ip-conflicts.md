# SIM-11 设备接口 IP 冲突

- 状态：待开发；阶段：推演二期；依赖：[SIM-08](sim-08-link-pair-rules.md)；预计：2 人天。

## 交付与接口

基于同一快照已解析接口地址按 VRF、地址和接口身份查重复，报告新增/消失/持续冲突、原配置来源与例外。仅对有输入的设备接口负责；anycast、VRRP/HSRP 虚 IP 等若无法识别，标 `needs_review`，不能报确定故障。缺解析或重叠网段不是相同 IP 冲突。结果缓存、可由拓扑定位端点。

## 验收

同 VRF 重复地址、不同 VRF、FHRP/anycast 疑例、缺地址、改名前后稳定 ID 与解析失败均有断言；无数据时为未检查而非零冲突。
