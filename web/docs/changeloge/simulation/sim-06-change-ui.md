# SIM-06 拓扑多设备变更交互

- 状态：待开发；阶段：推演二期；依赖：[SIM-05](sim-05-candidate-snapshot.md)；预计：3 人天。

## 交付与交互

拓扑右键/键盘菜单“加入变更”，侧栏列出已选设备及 `未编辑/已保存/脚本待确认/有错误`。设备编辑器提供完整配置与脚本两种入口；展示原配置、候选全文、可定位 diff 和脚本逐条转换结果。底部“变更推演”先列检查范围与当前业务意图版本，只有全部设备输入有效才可创建候选；长任务进入现有 jobs 状态页。切换快照/关闭有未存草稿时提示；页面永远显示这是仿真候选。

## 验收

浏览器双用户、两设备不同输入模式、`undo`/删除 diff、脚本不支持、版本冲突、网络/快照切换、失联重试、暗/亮主题与键盘菜单通过；旧技术拓扑和领导页回归。
