# SIM-10 有界黑洞与不可达见证

- 状态：待开发；阶段：推演二期；依赖：[SIM-09](sim-09-loops.md)；预计：3 人天。

## 交付与接口

对已声明的业务目的网段、起点及协议范围，用 Batfish `reachability` 的失败 disposition 和 traceroute 分析候选与基线，记录流例、停止节点/接口、路由/ACL 证据和“疑似原因”。范围默认只来自已登记业务意图或用户显式有限输入，拒绝无限全网扫描；不把任意不可达都标为路由黑洞，区分过滤、无路由、Null route、未建模、未覆盖。缺源、模型限制、配额/截断返回 `unknown`。可下钻到技术结果。

## 验收

四设备配置中制造限定目的前缀的丢弃和 ACL 阻断，核对原 SDK disposition 与分类；没有见证、超时、超限、源网段歧义以及旧结果引用均正确表达。
