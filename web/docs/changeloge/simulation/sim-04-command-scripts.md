# SIM-04 配置脚本输入、受限转换与预览

- 状态：待开发；阶段：推演二期；依赖：[SIM-03](sim-03-full-config.md)；预计：3 人天。

## 交付与接口

`POST /change-drafts/{id}/devices/{device_id}/script-preview` 接收脚本文本、基线哈希、厂商/语法标识；返回逐命令 `applied|unsupported|conflict`、生成的完整候选配置引用和差异。只有全部命令可验证转换且用户保存预览后才成为候选输入。先用真实 Cisco 四设备配置实现公开声明的 IOS 最小命令子集（接口描述/IP 地址及对应 `no` 删除），按语法上下文解析增删，不做任意文本追加；BGP/OSPF/ISIS/ACL 等未登记脚本命令先引导完整配置模式，后续按厂商单独扩展。未知模式、命令或厂商整体阻止发布。原脚本、转换器版本与生成配置摘要均保留审计。华为/H3C 等未验证语法显示“不支持脚本模式，可用完整配置”，不能伪称转换成功。

## 验收

每个登记命令有正反例、顺序依赖、`no` 删除、重复/冲突、非法跨设备命令、部分失败不落候选、重试幂等与输出配置 SDK 可解析的集成测试。明确能力矩阵；不下发设备、不承诺任意厂商 CLI。
