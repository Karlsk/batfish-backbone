# SIM-03 完整候选配置与前后差异

- 状态：待开发；阶段：推演二期；依赖：[SIM-02](sim-02-change-drafts.md)；预计：2.5 人天。

## 交付与接口

`PUT /change-drafts/{id}/devices/{device_id}/candidate-config` 保存该设备**完整配置**及其基线内容哈希；GET 读分段预览和差异。每次覆盖需匹配草稿版本和基线哈希，正文落受控文件卷并按上限验证；同内容重试幂等。差异把新增、删除（包括 `undo` 语义的删除）和改动明确标记，不自动生成厂商命令。未提交候选的已选择设备使草稿保持 incomplete；候选解析质量由后续 SDK 初始化确认。

## 验收

两设备分别编辑、旧版冲突、未保存设备阻止推演、超大/非法编码/敏感字段日志脱敏、相同重试、基线不变和差异行号均通过。保留旧配置文件与手工 ZIP 流程。
