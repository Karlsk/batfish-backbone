# SIM-02 多设备拟变更草稿与审计

- 状态：待开发；阶段：推演二期；依赖：[SIM-01](sim-01-intent-v2.md)；预计：2.5 人天。

## 交付与接口

`POST/GET/PATCH/DELETE /api/v1/networks/{id}/change-drafts` 创建、列出、修改、废弃草稿；基线只允许该网络就绪的不可变快照。草稿记录多个稳定设备 ID、输入模式、每台状态、作者/时间、`expected_version`、内容摘要与审计，候选创建后锁定本版输入。仅管理员可写、成员可读；不存在的设备、跨网络设备、已删除基线、重复加入及并发编辑明确拒绝。草稿不动真实设备、不创建引擎快照，后续通过受控 service 编排。

## 验收

真实 PostgreSQL 下双用户/并发版本、改名设备、两设备编辑、删除/恢复、基线删除引用保护和幂等创建通过；原故障场景、comparison API 不回退。
