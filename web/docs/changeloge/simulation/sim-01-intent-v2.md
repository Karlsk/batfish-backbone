# SIM-01 业务关注项升级为版本化意图

- 状态：待开发；阶段：推演二期；依赖：[CMDB-11](../cmdb/cmdb-11-acceptance.md)；预计：3 人天。

## 交付与接口

在现有 `business_concerns` 历史版本上增加源/目标规范 IPv4 地址或网段、起点、协议/端口、期望 `reachable|isolated` 和可选路径策略（必经/避开稳定设备 ID、最大跳数）；旧关注项向后兼容并标记未设置新字段。管理员按 `expected_version` 修改，成员读取；快照检查固定意图版本及当时解析到的设备映射。源/目标网段和端口按现有选项白名单与复杂度上限校验，不接受任意 SDK 表达式。隔离规则按两个方向独立执行。

## 验收

旧版关注项/汇报仍可读取；历史版本不可变；地址规范化、端口/协议约束、跨网络设备、路径策略冲突、权限与并发冲突有 PostgreSQL/API 测试。OpenAPI 与前端类型同步，暂不运行检查。
