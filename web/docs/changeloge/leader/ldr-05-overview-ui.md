# LDR-05 领导端日常总览与网络下钻

- 状态：已完成；阶段：领导端；依赖：[LDR-04](ldr-04-overview-api.md)；预计 2.0 人天。
- 共享约束：[领导端设计](../../leader-design.md)、[前端规范](../../frontend.md)。

## 需求与接口

领导首页默认展示全部共享网络的可信汇总：就绪/待准备/警告、未检查/检查中/结果可读，业务关注项入口、最近变更和可行动下一步。点击网络进入该网络的快照质量、关键关注项、相关任务和结果来源；每一项链接保留固定 ID 与时间。没有数据时只给入门动作，不使用演示数据。

页面消费 LDR-04 读模型、单网络详情及已有详情 API。总览分页按需加载；网络/快照切换、旧请求晚返回和会话变更不能串数据。质量限制、截断、服务未就绪与任务中断在结论层可见。
