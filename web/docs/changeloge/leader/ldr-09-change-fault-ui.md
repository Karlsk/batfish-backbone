# LDR-09 变更与故障领导视图

- 状态：待开发；阶段：领导端；依赖：[LDR-08](ldr-08-adv-guided-checks.md)；预计 2.0 人天。
- 共享约束：[领导端设计](../../leader-design.md)、[前端规范](../../frontend.md)、[ADV-18 验收](../../advance-phase3-acceptance.md)。

## 需求与接口

覆盖 ADV-11～18：领导端选择同网络两份就绪快照，固定左基线右候选，展示配置文件变化、路由新增/消失与限定 flow 的可达性变化；故障路径从原始基线选设备/接口、预览派生关系、显式提交并等待快照就绪，再进入影响比较。业务关注项只在其 flow 与结果范围确实匹配时显示相关提示，不能把未经检查的业务标为受影响。

复用现有 changes/fault API 与 LDR-06 运行记录。预览必须说明原始快照不被改写，失败/未知/解析警告阻断成功链接；配置行与双侧 trace 通过技术端深链按需查看。

## 改动位置与步骤

- `web/frontend/src/features/leader/changes/`：比较故事页和故障向导的领导视图；复用已有网络/快照与候选加载逻辑，不复制 SDK 调用。
- 先写固定方向、显式范围、失败/未知、派生不变性、业务映射版本和深链测试，再实现；真引擎上用已知差异双快照浏览器复核。

## 验收

配置行、静态路由与差异可达性方向和 ADV-18 固定样例一致；无差异只解释在给定范围内；失败派生不能进入比较；切换网络后旧响应不覆盖新上下文。前端单测/API 检查/类型/构建/格式、真实浏览器与 LDR-01～08 累计回归通过。

## 非目标与完成记录

不自动穷举所有故障组合或推断现场业务中断。记录版本、数据来源与限制。
