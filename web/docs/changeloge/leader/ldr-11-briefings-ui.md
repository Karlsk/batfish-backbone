# LDR-11 固定汇报与会议视图

- 状态：已完成（2026-09-28）；阶段：领导端；依赖：[LDR-10](ldr-10-briefings-api.md)；预计 2.0 人天。
- 共享约束：[领导端设计](../../leader-design.md)、[前端规范](../../frontend.md)。

## 需求与接口

领导端汇报列表、创建向导、固定详情与 `/leader/briefings/{id}/present` 全屏会议页。创建时选择已完成且同来源的检查结果，确认系统事实与警告，标题/备注作为人工内容单独标注。详情永远按冻结版本展示，后续新检查不覆盖；证据不可用时保留结论和固定 ID，并禁用失效深链。会议页以大字号、拓扑/变化可视化和有限动效呈现，提供团队内登录链接、打印与浏览器另存 PDF。

使用 LDR-10 接口与共享主题；打印 CSS 保留范围、版本、时间、警告及来源，隐藏导航/交互控件。深浅主题、键盘、焦点和 `prefers-reduced-motion` 一致。

## 改动位置与步骤

- `web/frontend/src/features/leader/briefings/`：列表、创建/版本详情、会议视图、打印样式；不把人工备注渲染成系统结论。
- 先写冻结不变、来源失效、权限、打印信息、两主题与减少动效测试，再实现；在真实双用户浏览器中打开同一汇报。

## 验收

创建者和另一成员读到相同固定事实；人工备注有来源标识；新增结果/改映射后旧报告不变；全屏与打印都能看清范围、版本和限制。前端单测/API 检查/类型/构建/格式、真实浏览器与 LDR-01～10 累计回归通过。

## 非目标与完成记录

不生成独立服务器 PDF/PPT，不公开发布。

## 完成记录

已在原 `web/frontend` 增加汇报列表、按网络/快照/已完成检查选择证据的创建页、不可变版本详情和独立全屏会议页。创建前显示固定结果摘要、模型覆盖与警告；版本详情将系统事实和人工标题/备注分开，编辑人工内容只生成新修订。来源失效时保持事实与固定 ID、关闭原始证据链接。会议页提供团队内链接、深浅主题、减少动效、全屏和浏览器打印/另存 PDF；打印保留来源、范围、版本、时间与全部模型警告。选择器显示名称及短 ID，避免同名网络/快照选错。
