# 前端设计与交互规范

## 视觉方向

面向日常办公的中文工作台：浅色背景、清晰字体、蓝色主操作、适量留白；固定侧栏和顶部网络/快照选择。以表格、表单、详情抽屉为主体，不做装饰性大屏。8px 间距体系，常用字号 14px，长设备名允许复制和完整查看，状态同时使用文字与图标，不能仅靠红绿区别。

优先适配 1280～1920px 桌面；窄屏允许表格横向滚动，核心提交操作不被遮挡。支持键盘导航、可见焦点、表单标签和错误说明。样式统一使用 Ant Design token，不在页面中散落独立颜色和尺寸。

## 页面结构与阶段

| 页面 | 第一层 | 第二层 | 第三层 | 阶段 |
| --- | --- | --- | --- | --- |
| 登录/用户管理 | 登录表单或用户列表 | 创建/停用/角色/重置密码 | 操作结果与会话失效说明 | 1 |
| 网络/快照 | 名称、状态、时间、创建者 | 上传向导、文件列表、解析摘要 | 配置内容、初始化诊断 | 1 |
| 概览 | 设备/接口数量、解析问题、下一步入口 | 问题列表 | 相关文件行 | 1 |
| 设备/接口 | 设备名、厂商、接口状态与 IP | VRF、协议属性 | 原始属性/配置文件 | 1 |
| 路由 | 网段、设备/VRF、下一跳、协议 | metric、管理距离、属性 | 完整结构化行 | 1 |
| 连通性 | 输入起点/目的、实际 flow、结论 | 所有返回路径和逐跳动作 | 原始 Trace/配置来源 | 1 |
| 任务 | 状态、名称、发起人、耗时 | 有效参数、来源、错误说明 | 原始结果导出 | 1 |
| 拓扑/BGP/ACL | 核心关系或结论 | 节点/会话/规则证据 | 原始分析结果 | 2 |
| 变更/故障 | 基线、候选、变化摘要 | 受影响路由/flow/设备 | 配置差异与逐跳证据 | 3 |

## 基础与高级参数

每个分析页面默认显示必要参数和有解释的默认值。“高级参数”展示服务器能力 schema 中已登记的 options，并在折叠状态显示“已启用 N 项高级设置”。基础/高级模式共用一个表单状态，切换不能悄悄删除用户填写的条件。

基础选择器提供设备、接口、VRF 的真实值；专家可切换到表达式输入。字面值交给后端正确转义为 SDK specifier，不能将包含括号、斜线的名称直接拼接成表达式。JSON 编辑入口是补充，只能编辑 options；执行前展示归一化参数与有效作用范围。服务端再次校验，不信任前端过滤。

未开放的能力不呈现可执行按钮。所有高级功能以同一结果契约返回，不让原始 SDK 列名泄漏成主要导航文字，但原始详情保留字段名供专家核对。

## 必须常驻的上下文

顶部显示网络与快照，结果卡保留执行时的快照名称/ID 和时间。切换顶部快照只改变后续查询上下文，不替换历史任务结果上的来源。尚未保存的表单变化需提示；旧请求晚返回时不能覆盖新快照的结果。

覆盖限制、初始化关键警告、ignore_filters、truncated、未知引擎状态必须在第一层可见。不可只在原始 JSON 中说明。摘要使用“在当前模型及所选条件下”，不声称实时网络可用。

## 首版连通性布局

```text
顶部：网络 [选择]    快照 [选择]    解析覆盖 [查看]
表单：起点设备/接口 [选择或表达式]    目的 IPv4 [填写]
      高级参数 [展开]                         [开始分析]
任务：排队 / 运行中 / 完成 / 失败 + 耗时
结论：flow 条件 + 各 disposition 的路径数 + 截断/模型限制
路径：按 flow 分组 → 路径选择 → hop 顺序 → 动作和规则详情
底部：[查看有效参数] [原始结果] [导出 JSON]
```

单条路由或 traceroute 返回成功不足以概括所有分支；保留多路径数量及未返回路径提示。NO_ROUTE、DENIED、LOOP 等原始 disposition 保留并配中文说明，未知枚举原样呈现，不能映射成“成功”。

## 状态、缓存与网络行为

查询 key 包含 network_id、snapshot_id、result_id 和参数；身份变化清理用户敏感缓存。任务轮询初始 2 秒、长时间任务降至 5 秒，终态停止；切回窗口刷新一次。分页、抽屉和原始详情按需加载，页面离开不会取消服务端任务。

初次加载、空结果、没有匹配设备、解析失败、服务不可用分别显示。权限失败提示无权限，禁止靠隐藏按钮代替后端校验。队列任务在 cancel_allowed=true 时显示“取消”；running 和已排队删除任务只显示状态和说明，不提供假取消。重新执行显示来源参数并创建新任务；初始化重试另建快照，页面明确展示新旧来源。

## 二、三阶段约束

拓扑默认三层推导视图；物理信息只在输入提供且能力支持时展示。默认聚焦一个设备及一跳邻居，上限 200 个可见节点；超限要求过滤，不把采样当完整拓扑。手动布局调整仅是视图，不修改网络配置。

差异页面基线在左、候选在右，全程固定方向；结果不按颜色单独解释。故障模拟采用“选择对象 → 预览变化 → 创建派生快照 → 选择分析范围”，不编辑原快照，不自动枚举所有故障组合。
