# ADV-04 BGP 会话工作台实施计划

基线：`a12256d55d`（ADV-03）。仅使用已交付的 BGP 分析及结果 API，不新增 SDK 参数。

1. 在独立 `/bgp` 页面提供状态/兼容性两种分析入口。默认无需用户填写参数；设备及远端设备选择器折叠到高级参数。提交使用固定快照、幂等键和已有任务页。
2. BGP 结果用专门的会话表承载：本地设备、远端设备、地址、原始状态作为首层；按状态精确筛选并分页。未知远端明示未知，不生成虚假目标。详情展开接口、VRF、AS、地址族及完整原始行。
3. 双端路由入口先恢复结果固定的网络/快照，再带设备名跳到已有路由分析；上下文选择被拒绝或组件卸载时不导航。
4. 先写组件交互测试并见到失败，再实现；随后运行目标测试、全前端/后端/浏览器、真实配置冒烟和 HTTPS 恢复双主题验收。回写 spec、索引、矩阵和证据后提交。

限制：列表是配置模型计算，不反映现场会话；本篇不做实时推送或自动修复。
