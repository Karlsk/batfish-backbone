# MVP-05 账号管理与审计实施计划

依据已确认 MVP-05；复用 MVP-04 身份/密码/会话版本和审计，不引入 users→auth 反向依赖。

- [x] 真实 PostgreSQL/API 测试先行：普通成员禁止管理、分页/参数校验、重名冲突、角色立即生效、停用/重置使所有旧会话失效。
- [x] UsersService 管理方法再次核对数据库实时身份；API 只验证/提取可信 Actor 并调用 service。装配层注入认证依赖，API 不直接导入其他模块。
- [x] 所有用户管理变更共用数据库事务锁；检查有效管理员计数，禁止最后一个有效管理员停用/降级。自己停用或降级也遵循同一规则，有其他有效管理员时允许，下一请求权限即时生效。
- [x] 创建/重置强制临时密码；停用、重置递增 session_version。重新启用不能复活旧 Cookie。角色变更每次请求读取实时角色。
- [x] 创建/启停/角色/重置与审计同事务；审计仅 actor/action/resource/outcome/request_id/time，不保存密码或完整请求。
- [x] 运行并发降级测试，证明有效管理员不能归零；真实 HTTP 冒烟覆盖创建/改密/停用/启用/重置及会话失效。
- [x] 独立审查、MVP-01～05 累计回归、文档与脱敏证据回写、提交后进入 MVP-06。

分页默认 50、最大 200。创建返回 201 用户公开字段；列表返回 items/offset/limit/total；PATCH 返回更新后的用户；reset-password 返回 204。id 为 UUID，所有公共用户响应排除 password_hash 与 session_version。
