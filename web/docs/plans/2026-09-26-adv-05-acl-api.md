# ADV-05 ACL 流量测试接口实施计划

基线：`4fc9780e92`（ADV-04）。仅对当前固定引擎与 Pybatfish 已登记的 `testFilters`、`resolveFilterSpecifier` 开放有类型入口。

1. 用 Cisco 合成 ACL 快照直接对照两问题的实际 SDK 参数、列和值；确认 permit、deny、隐式 deny 与过滤器解析的原始语义，不推测源配置行。
2. 为两个问题登记请求 DTO、registry、api、controller。api 只校验与转发；service 固定上下文、权限、模型覆盖和业务状态；controller 构建 HeaderConstraints 与受限选择器并转换 SDK 答案。
3. testFilters 最小字段为源/目标 IPv4 与过滤器，设备可选；专家选项包含协议、端口。resolve-filters 仅返回模型实际解析的过滤器清单。未知 kwargs、覆盖上下文、缺失过滤器和不可靠厂商覆盖均不能产生允许结论。
4. 测试先行并经真实 SDK 对照后，运行 ADV-05 与先前所有 MVP/ADV 的累计后端、前端、浏览器、HTTPS 部署恢复和双用户门槛。回写 spec、矩阵和脱敏证据，单篇提交后进入 ADV-06。
