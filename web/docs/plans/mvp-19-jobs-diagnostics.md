# MVP-19 实施计划

基线9570f67f48，依赖11/18已完成。

1. 任务中心按状态/当前网络/本人筛选分页；详情显示真实状态/阶段与不可变来源，无伪百分比。查询按任务身份隔离，活动任务2秒后退避5秒，终态停止轮询，离开不取消。
2. queued且cancel_allowed并拥有权限才显示取消；409解释领取竞态并刷新。失败/取消/中断任务可显式重试，保持幂等键；未知引擎给恢复说明，服务端最终校验。初始化重试展示旧任务/旧快照与新来源，跳转新任务，不修改旧快照。
3. 快照质量/模型覆盖摘要常见；诊断分严重程度分页，缺位置不造行号。源文件通过受控file_id分页读取，按实际返回number高亮，仅高亮已知正整数位置，缺文件清晰报错；原始诊断按详情展开。
4. 先写轮询/卸载不取消/取消权限/缺位置测试；真实两拓扑浏览器增加任务详情与刷新、诊断/文件行查看。排队取消与重试用受控暂停worker的隔离场景，恢复后验真实终态。
5. 独立只读审查，累计后端/双拓扑smoke/全部前端与浏览器/契约构建验证，回写证据后提交，继续MVP-20。
