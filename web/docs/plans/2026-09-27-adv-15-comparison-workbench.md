# ADV-15 变更对比工作台实施计划

> 按已确认的 ADV-15、`spec-dev` 和累计门槛执行；以 ADV-14 提交 `23e19dfe79` 为基线。

**目标：** 在技术工作台选择同一网络两份就绪快照，固定基线（左）与候选（右），逐级查看配置、路由及限定范围的可达性变化。

**结构：** 新增 `features/changes/` 页面与结果组件，使用现有有类型 API、任务轮询、ResultEnvelope、TraceSteps 和详情抽屉。页面按 network/comparison 重新挂载，查询键包含比较/任务/结果 ID，避免迟到响应覆盖新选择。配置文件差异先读摘要，单个文件详情按需读取；路由和可达性结果分页，第一层显示方向、模型覆盖与截断，第二层显示两侧证据，第三层保留原始行。

**交互：** 创建时基线和候选都必选且不能相同，交换按钮只交换草稿，不改变已有不可变比较；保存后生成新 ID。比较列表可选择历史记录，旧结果通过任务/结果链接可追溯。配置 diff 无必填参数；路由 diff 默认全节点，专家可填节点/前缀；可达性必须填目的 IP 与起点，高级折叠保留来源 IP、协议、端口和路径上限。成功无差异只说明所选范围，失败/覆盖有限/版本冲突/截断明确显示。
