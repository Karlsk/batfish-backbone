# ADV-03 BGP 模型状态与兼容性接口实施计划

**目标：** 在固定引擎/SDK 上提供两种 BGP 会话表格分析，并保留原始模型证据与覆盖限制。
**Spec：** [ADV-03](../changeloge/advance/adv-03-bgp-api.md)，依赖 ADV-02 已提交。

## 约束

- API 只校验、service 编排与结果语义、controller 调用固定公开 SDK 问题；不接任意 question/method。
- 请求最小参数为默认 `options.mode=status`，高级只放 typed `nodes`、`remote_nodes`；拒绝其它 kwargs。
- 会话结果保持 SDK 原始列和值；只附模型解释，不把 ESTABLISHED 翻译成现场会话健康。Huawei/H3C IPv6 等未模拟范围应明确提示。
- 真实测试使用同一固定 Batfish/JAR、Pybatfish 及配置快照；独立序列化 SDK 答案逐行比较。状态枚举以当前源码和实际 SDK 输出为准。
